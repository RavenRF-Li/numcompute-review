# NumCompute-Stream 测试计划

主计划包含 54 个单元或组件测试场景及 4 个交付验证场景，另有阶段 A 的 3 个、阶段 B 的 5 个和阶段 C 的 3 个补充场景。测试使用标准库 `unittest`、`unittest.mock`、`tempfile` 和 `numpy.testing`。数组以表中行顺序构造，`NaN` 表示 `np.nan`，一维数列作为特征时显式构造成单列二维数组。可手算的计数、标签及列顺序精确比较，浮点结果按事先约定的合理容差比较，NaN 使用 `isnan` 检查。

开始阶段 C 前已完成 41 项 2.2 测试。阶段 C 完成 T31–T36、T40–T51 和 C01–C03，Pipeline 8 项、指标 7 项、Trainer 6 项均通过。现有 `aiml`（Python 3.12.13、NumPy 2.5.2、pytest 9.2.0）合跑全量套件，704 项通过、0 项失败，其中 642 项为 2.1 旧回归。另有 4 条原有 NumPy 配置输出警告。T52–T54 与 V01–V04 待实施。详见 [实施计划](implementation_plan.md)。
